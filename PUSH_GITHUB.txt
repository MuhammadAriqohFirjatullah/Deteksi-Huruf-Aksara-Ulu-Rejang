## ⚠️ PENTING: Setup Credentials untuk GitHub

Sebelum push, pastikan Anda sudah setup:

### A. SSH Key (Recommended)
https://docs.github.com/en/authentication/connecting-to-github-with-ssh

### B. Personal Access Token (Alternative)
1. Ke https://github.com/settings/tokens
2. Click "Generate new token (classic)"
3. Pilih scopes: `repo`, `admin:repo_hook`
4. Copy token dan simpan
5. Saat push, masukkan token sebagai password

## 🔍 Troubleshooting

### Error: "Repository not found"
- Pastikan URL repository benar
- Pastikan credentials GitHub benar
- Repository harus sudah dibuat di GitHub

### Error: "Permission denied (publickey)"
- Setup SSH key atau gunakan HTTPS + PAT
- Tutorial: https://docs.github.com/en/authentication

### Error: "fatal: 'origin' already exists"
- Repository sudah di-push sebelumnya
- Jalankan: `git remote remove origin` kemudian ulangi

### Error: "Everything up-to-date"
- Tidak ada perubahan untuk di-push
- Pastikan sudah ada commits baru
